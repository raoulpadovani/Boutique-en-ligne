# boutique en ligne

🛒 README — Boutique en ligne (Backend PHP)
📌 Description

Ce projet est le backend d'une boutique en ligne développé en PHP. Il permet de gérer les utilisateurs, les produits, les commandes et les paiements via une API ou une interface serveur.

⚙️ Fonctionnalités principales
🔐 Authentification des utilisateurs (inscription, connexion)
👤 Gestion des comptes clients
📦 Gestion des produits (CRUD : créer, lire, mettre à jour, supprimer)
🛍️ Gestion du panier
